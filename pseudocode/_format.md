# 伪代码统一格式规范

> 所有 `pseudocode/` 下的算法伪代码请遵循本格式。原则是：**语言无关、可读性优先、完整可追溯**。

## 统一模板

```
# 算法名称（如：线性回归（梯度下降法））

## 输入
- X：特征矩阵，形状 (m, n)
- y：标签向量，形状 (m,)
- α：学习率
- iterations：迭代次数

## 输出
- θ：拟合得到的模型参数，形状 (n,)

## 伪代码
1. 初始化 θ 为全零向量
2. 归一化特征 X
3. FOR i FROM 1 TO iterations:
4.     y_pred = X · θ
5.     error = y_pred - y
6.     gradient = (Xᵀ · error) / m
7.     θ = θ - α · gradient
8.     loss = MSE(y, y_pred)
9. RETURN θ

## 复杂度分析
- 时间复杂度：O(iterations · m · n)
- 空间复杂度：O(m · n)
```

## 编写原则

1. **语言无关性**：不绑定具体编程语言，侧重算法逻辑；
2. **可读性优先**：用自然语言描述，避免语法细节；
3. **完整可追溯**：明确输入输出、中间变量、边界条件；
4. **渐进式展开**：核心算法先给整体框架，再展开细节。

## 命名约定

- 矩阵 / 向量用大写 / 小写粗体或首字母提示（如 `X`、`θ`）；
- 循环用 `FOR ... FROM ... TO ...`；
- 条件用 `IF ... THEN ... ELSE ...`；
- 赋值用 `=`；近似 / 更新用 `θ = θ - α·gradient` 形式表达。
