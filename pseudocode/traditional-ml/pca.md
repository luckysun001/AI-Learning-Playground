# 主成分分析（PCA）

## 输入
- X：样本矩阵，形状 (m, n)
- k：目标维数

## 输出
- W：投影矩阵，形状 (n, k)（前 k 个主成分方向）
- Z：降维后数据，形状 (m, k)

## 伪代码
1. 中心化：X = X - mean(X, axis=0)          # 每列减均值
2. 计算协方差矩阵：Σ = (1/m) · Xᵀ · X        # 形状 (n, n)
3. 特征值分解：Σ · v = λ · v
4. 将特征值 λ 降序排列，取前 k 个对应的特征向量 v_1..v_k
5. W = [v_1, v_2, ..., v_k]                  # 形状 (n, k)
6. Z = X · W                                 # 降维投影
7. RETURN Z, W

## 复杂度分析
- 时间复杂度：O(n² · m + n³)（协方差 + 特征分解）
- 空间复杂度：O(m · n + n²)

## 说明
前 k 个主成分解释的方差占比 = Σ_{i=1..k} λ_i / Σ_j λ_j，用于决定 k。
大数据可用随机 SVD（Randomized SVD）近似。
