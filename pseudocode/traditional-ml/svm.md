# 支持向量机（SVM，软间隔 + 核技巧）

## 输入
- X：样本矩阵，形状 (m, n)
- y：标签，取值 {-1, +1}
- C：惩罚系数（容忍误分程度）
- K(·,·)：核函数（如 RBF: exp(-γ||x-z||²)）

## 输出
- 支持向量与对应拉格朗日乘子 α
- 决策函数 sign( Σ α_i y_i K(x_i, x) + b )

## 伪代码（对偶问题求解思路）
1. 构造核矩阵：Kmat[i][j] = K(X_i, X_j)        # 形状 (m, m)
2. 求解二次规划（QP）：
      max_α  Σ α_i - ½ ΣΣ α_i α_j y_i y_j Kmat[i][j]
      s.t.  0 ≤ α_i ≤ C,  Σ α_i y_i = 0
3. 支持向量 = { i : α_i > 0 }
4. 计算偏置 b = mean( y_i - Σ α_j y_j K(x_j, x_i) )  over 支持向量
5. 预测：
      f(x) = Σ_{i ∈ 支持向量} α_i y_i K(x_i, x) + b
      ŷ = sign(f(x))

## 复杂度分析
- 训练：O(m² ~ m³)（核矩阵与 QP 求解）
- 预测：O(支持向量数 · n)

## 说明
线性核时可用更高效的对偶坐标下降（SMO / Liblinear）。C 大→硬间隔倾向（过拟合），C 小→宽间隔（欠拟合）。
