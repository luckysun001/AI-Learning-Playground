# 特征工程（Feature Engineering）

> 「数据和特征决定机器学习上限，模型和算法只是逼近这个上限。」
> 把原始数据转化为模型更易学习的形式：处理缺失、编码类别、缩放数值、构造新特征、筛选重要特征。
> 详见文档：[docs/traditional-ml/feature_engineering.md](../traditional-ml/feature_engineering.md)

## 输入
- X_raw：原始特征矩阵，形状 (m, n)（含数值 / 类别 / 缺失）
- num_cols：数值列索引集合
- cat_cols：类别列索引集合
- y（可选）：用于目标编码 / 特征选择
- 阈值参数：缺失删除阈值、分箱数、方差阈值等

## 输出
- X_proc：处理后的数值矩阵，可直接喂给模型

## 子算法 A：缺失值处理
FOR 每列 c：
1. IF 缺失比例 > 阈值（如 0.6）且非关键信息 → 考虑删除该列
2. ELSE IF c ∈ num_cols → 填充 `median(c)`（抗离群）或 `mean(c)`
3. ELSE（类别列）→ 填充单独类别 `'missing'`，或众数 `mode(c)`

## 子算法 B：类别编码
- **One-Hot**：FOR 每个类别列 c → 生成 d 个 0/1 列（d = 取值数，或 `drop_first` 降维）
- **Label / Ordinal**：有序类别（如学历）映射为 0,1,2...（保留序关系，模型不会误判大小）
- **WOE（证据权重，风控评分卡）**：
  - 先按好坏比对连续/类别特征**分箱** bin
  - FOR 每个箱 b：
    - `good = count(y=0 且 x∈b); bad = count(y=1 且 x∈b)`
    - `WOE_b = ln( (good + 0.5)/total_good / (bad + 0.5)/total_bad )`
  - 映射 x → 所在箱的 WOE 值（要求单调性，否则调整分箱）
- **目标编码**：`x_j → mean(y | x_j)`（须配合 CV 防泄漏，见末尾）

## 子算法 C：数值缩放
- **Z-score（标准化）**：`x' = (x - μ) / σ`（μ, σ 来自训练集；适合 SVM / 梯度下降 / PCA）
- **Min-Max（归一化）**：`x' = (x - min) / (max - min) ∈ [0,1]`（适合边界敏感模型）
- **Robust Scaling**：`x' = (x - median) / (Q3 - Q1)`（抗离群值）

## 子算法 D：特征构造
- 日期：拆 年 / 月 / 日 / 星期 / 是否周末
- 比值 / 占比：`a / (a + b)`
- 多项式特征：`x1·x2`、`x1²` ...
- 交叉特征：类别组合

## 子算法 E：特征选择
- **方差阈值**：删除方差 < 阈值的常数列（无区分度）
- **卡方检验**：筛选与 y 最相关的类别特征
- **RFE（递归特征消除）**：递归删除最不重要特征（基于模型系数 / 重要性）
- **树模型重要性 / L1 正则**：用重要性或稀疏系数筛选

## 防数据泄漏（关键，务必遵守）
所有 `fit`（均值 / 最大最小 / 编码器参数）必须**只在训练折内**拟合：
1. 用 `Pipeline(预处理, 模型)` 包裹整个流程
2. CV 中：`fit_transform` 作用于 `train_idx`，`transform` 作用于 `valid_idx`
3. **严禁**用全量数据的统计量去缩放 / 编码测试集（会虚高效果，导致线上崩塌）

## 复杂度分析
- 缺失 / 缩放 / 编码：O(m·n)
- 特征选择（RFE）：O(迭代次数 · 单次训练成本)
- 空间：O(m·n)（One-Hot 后可能增维，高基数类别慎用）

## 关键细节
- One-Hot 后**勿再标准化**（已为 0/1）；树模型可不吃缩放
- 高基数类别（如城市）直接 One-Hot 会维度爆炸 → 改用目标编码 / WOE / 嵌入
- WOE 要求单调，否则需重新分箱
- 用 Pipeline 串起预处理 + 模型，保证 CV 与上线一致性
