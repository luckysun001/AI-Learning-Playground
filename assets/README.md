# assets

本目录用于存放项目的图片、数据样例、知识图谱脑图等静态资源。

- 知识图谱脑图（每个模块一张）
- 关键算法流程示意图
- 实战案例的结果可视化样例

> 资源请在文档中以相对路径引用。例如在本目录中引用本目录的图片：`![KMeans 聚类](./kmeans_pca.png)`；
> 若在 `docs/traditional-ml/` 下的文档中引用，则写作 `../../assets/kmeans_pca.png`。

**当前已有资源：**

| 文件 | 说明 |
|---|---|
| `kmeans_pca.png` | KMeans 聚类结果经 PCA 降维后的可视化 |
| `user_clusters_pca.png` | 用户分群案例的 PCA 可视化 |
